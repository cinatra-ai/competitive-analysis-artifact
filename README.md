# Competitive Analysis

A semantic artifact that stores the strategic view of your competitive landscape. Attach a competitive-analysis document (Markdown, plain text, or PDF) and the artifact preserves named competitors, feature and pricing comparisons, SWOT analyses, positioning maps, win/loss patterns, and recent competitive moves for later reference. This is the product-marketing and founder layer — not the sales-floor battlecard view.

**Purpose.** Keep a living, structured record of the market so strategy leads, writers, and founders share a common, up-to-date context when drafting positioning, roadmap rationale, or outbound copy.

**Accepted inputs.** Markdown (`.md`), plain text (`.txt`), or PDF. The artifact runs a semantic classifier with a confidence threshold of 0.7 to decide whether an attachment qualifies as a competitive-analysis document before storing it.

**Usage.** Upload a document through the Cinatra workspace. If the classifier accepts it, the artifact becomes available as reference context for agents that produce positioning copy, strategy briefs, or outbound messaging. No credentials or additional configuration are required.

**Troubleshooting.** If an upload is rejected, verify the document contains explicit competitor names, a comparison matrix, SWOT section, or positioning analysis — brief battlecard-only call scripts or single-competitor pricing screenshots will not pass the classifier threshold.

## Works with

- Cinatra workspace (attach as context for positioning and strategy agents)

## Capabilities

- Capture a structured landscape view of competitors and alternatives
- Preserve SWOT, positioning, and win/loss patterns for later reference
- Brief writers and strategy leads with up-to-date landscape context
- Attach as reference context when drafting positioning or outbound copy
