# Competitive Analysis

A strategic view of the competitive landscape — named competitors, feature and pricing comparisons, SWOT, positioning maps, recent competitive moves, and win/loss patterns. This is the product-marketing and founder view of the market, kept distinct from sales-floor battlecards.

## Capabilities

- Capture a structured landscape view of competitors and alternatives
- Preserve SWOT, positioning, and win/loss patterns for later reference
- Brief writers and strategy leads with up-to-date landscape context
- Attach as reference context when drafting positioning or outbound copy
